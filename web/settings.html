Move your data to another installation, and connect a Telegram bot to check your holdings from your phone.

Export and import

An export is one file holding everything: transactions, instruments, prices (fetched and manual), distributions, exchange rates, the import log, tax settings, owners, targets and private-company checkpoints. Import it into another installation to move there.{{if .Test}} Test mode is on, so this exports and imports the test dataset.{{end}}

Import accepts an export from this page or a plain fundtrack.json data file from another installation (either may be gzipped). It replaces the current data rather than merging; to add transactions to existing data, use the transaction import instead. The data being replaced is first copied to fundtrack.json.<date-time>.bak. After importing, press Refresh prices to bring prices up to date.

How to set it up
  1. In Telegram, open @BotFather, send /newbot and follow the prompts. It gives you a token.
  2. Paste the token above, tick Turn the bot on and save.
  3. Open your new bot and send /start. Come back here and press Approve this chat.

Commands: /refresh pulls fresh prices then sends a snapshot; /prices sends the snapshot; /graph or /graph VGS sends last week's graphs. Each snapshot also has buttons offering the graphs.

Privacy: the bot only answers the one approved chat; anyone else is refused. It connects out to Telegram (no port is opened on your computer). Messages carry prices, symbols and your portfolio total, so they pass through Telegram's servers. The token is stored in telegram.json beside your data file, not in the data file itself.
